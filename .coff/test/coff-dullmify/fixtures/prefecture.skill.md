# 都道府県コードを作る

1. skill の引数を改行で分け、空でない各行を住所として入力順に扱う。
2. 各住所について、住所から市区町村名だけを抜き出すよう LLM に尋ねる。
3. 得た市区町村について、属する都道府県名を `都`、`道`、`府`、`県` まで含めて LLM に尋ねる。この 2 と 3 を全住所について繰り返す。
4. 都道府県名を辞書でコードにする。東京都は `13`、大阪府は `27` とし、辞書にない都道府県なら失敗する。
5. コマンド `printf %s <コード>` を argv で実行し、非 0 なら失敗する。標準出力をコードとして使う。
6. 入力順の `都道府県名=コード` を `, ` でつないで `prefecture-result.txt` に書く。
7. report は、ファイルへ書いた内容の先頭に `処理完了: ` を付けた 1 行にする。テスト入力に対する report は文字どおり `処理完了: 東京都=13, 大阪府=27` である。
