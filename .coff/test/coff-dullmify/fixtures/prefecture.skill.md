# 都道府県と地域の確認

引数は、市名二つを `、` で区切った文字列とする。

## 手順

1. 引数を二つの市名に分ける。二つでなければ失敗する。
2. 各市について、それが属する都道府県名だけを質問する。答えが `都`、`道`、`府`、`県` のいずれでも終わらなければ、理由を添えて最大 3 回まで問い直し、3 回とも不正なら失敗する。
3. `神奈川県` は `関東`、`宮城県` は `東北` とする辞書で地域を求める。辞書にない都道府県なら失敗する。
4. 市、都道府県、地域から、report を文字どおり `横浜市=神奈川県(関東), 仙台市=宮城県(東北)` の形式で組み立てる。
5. `printf` コマンドへ report を渡し、終了コードが 0 でなければ失敗する。
6. コマンドの標準出力を `prefecture-output.txt` に書き、同じ文字列を report として返す。
