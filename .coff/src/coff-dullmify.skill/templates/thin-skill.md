この SKILL.md と同じディレクトリにある `scripts/run` の絶対パスを求め、次の手順だけを行う。

1. `sh <絶対パス>/scripts/run start` を、ほかのコマンドと組み合わせずに実行する。
2. 最後の出力行にある JSON の `write` が指すファイルへ、skill に渡された引数をファイル書き込みツールで書く。
3. `sh <絶対パス>/scripts/run continue <run>` を、ほかのコマンドと組み合わせずに実行する。
4. 各呼び出しの最後の出力行にある JSON だけで次を決める。
   - `prompt` があれば、`input` について `prompt` が求める答えだけを得る。答えるために必要な参照やユーザーへの確認は行ってよいが、それ以外の操作はしない。答えを `write` のファイルへファイル書き込みツールで書き、同じ `continue` を呼ぶ。
   - `done` があれば、`report` を一字も変えずに表示して終わる。
   - `failed` があれば、その値を一字も変えずに表示し、手順外の対処をせずに終わる。
5. 最後の行が JSON でなければ、呼び出しの出力を表示して終わる。呼び出しが終わらないうちに制御が戻った場合は、終わるまで待って最後の出力を読む。出力がなければ同じ `continue` を呼び直す。
